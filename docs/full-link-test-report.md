# 接口更新与全链路测试报告

## 1. 接口更新摘要

### 本轮新增/补齐接入
- `GET /api/admin/admin/order/list`
  - 平台运营方订单列表已改为真实接口，不再返回前端空分页占位。
- `GET /api/admin/admin/report/list`
  - 平台运营方报告列表已改为真实接口，不再返回前端空分页占位。
- `GET /api/admin/admin/report/{reportId}`
  - 平台运营方报告详情已接入真实接口。

### 本轮更新替换的旧接口
- 平台运营端订单管理
  - 旧实现：本地空态 stub。
  - 新实现：对接 `GET /api/admin/admin/order/list`，并在前端兼容关键字、状态、支付状态、寄样状态筛选。
- 平台运营端报告管理
  - 旧实现：本地空态 stub。
  - 新实现：对接 `GET /api/admin/admin/report/list`，并在前端兼容关键字、状态、盖章状态筛选。
- 附件预览
  - 旧实现：统一 blob URL + iframe，文件服务返回 `application/octet-stream` 时，图片/PDF/文本类预览不稳定。
  - 新实现：
    - 图片：按扩展名强制指定 mime 后生成 blob 预览。
    - PDF：按 `application/pdf` 生成 blob 预览。
    - 文本/Markdown/JSON/CSV：直接读取文本内容预览。
    - Office：支持 Office Online 内嵌预览，失败时回退新窗口打开。

### 已废弃/下线的旧接口
- 未在本轮继续新增废弃接口；历史遗留的假接口/空接口主要已集中替换到管理端订单、报告模块。

### 已替换的 mock / 占位逻辑
- 平台运营方订单列表空分页占位已替换为真实接口。
- 平台运营方报告列表空分页占位已替换为真实接口。
